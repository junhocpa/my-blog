네이버 부동산 공개 매물 정보를 개인 열람 목적으로 수집. 정확한 정보는 원본을 확인하세요.

수집·주기 실행 방법
  1. 처음 한 번: node apps/yeouido-jeonse/collector/collect.js --verify — 네이버 API 스펙이 실제로 맞는지 확인합니다(이 코드는 네이버 접속이 차단된 환경에서 작성되어 라이브 검증되지 않았습니다).
  2. 평소 수집: node apps/yeouido-jeonse/collector/collect.js
  3. 1일 2회 자동 실행(macOS/Linux): 0 8,20 * * * cd <저장소> && /usr/bin/node apps/yeouido-jeonse/collector/collect.js >> apps/yeouido-jeonse/run-logs/cron.log 2>&1
  4. Windows는 작업 스케줄러에 매일 08:00·20:00으로 등록합니다. 자세한 내용은 앱 폴더의 README.md 참조.
