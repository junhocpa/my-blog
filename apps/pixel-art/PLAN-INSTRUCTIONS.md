# Plan 서브에이전트 지침 — 픽셀 아트 에디터

## 역할
픽셀 아트 에디터 웹앱의 구현 계획(spec.md)을 작성한다. **코드는 작성하지 않는다.**

## 요구사항 (사용자 요청)
- 16x16 격자에 도트를 찍어서 그림을 그리는 픽셀 아트 에디터
- 완성한 그림을 PNG로 저장(다운로드)할 수 있어야 한다
- 색상 팔레트 포함

## 프로젝트 제약 (CLAUDE.md)
- 순수 HTML, CSS, JavaScript만 사용. 프레임워크/번들러 금지.
- 앱은 `apps/pixel-art/` 폴더 안에 자체 완결되어야 한다.
- 외부 라이브러리 최소화 (Canvas API 등 브라우저 내장 기능으로 충분함).
- 모바일에서도 사용 가능해야 한다 (터치로 도트 찍기 지원).
- 블로그의 다른 파일은 건드리지 않는다.
- `index.html`을 file:// 로 직접 열어도 동작해야 한다 (`<script defer>` 사용, ES 모듈 지양).

## spec.md에 포함할 내용
1. 앱 개요 및 핵심 사용 흐름 (색 선택 → 도트 찍기 → PNG 저장)
2. 기능 목록 — 최소 포함:
   - 16x16 격자 캔버스, 클릭/드래그로 도트 찍기, 터치 지원
   - 색상 팔레트 (기본 색상 세트 + 현재 선택 색 표시. 커스텀 색상 피커 포함 여부는 계획 단계에서 결정해 명시)
   - 지우개(또는 투명색) 및 전체 지우기
   - PNG 다운로드 (16x16 원본 크기로는 너무 작으므로 확대 배율을 정해 명시, 예: 320x320)
3. 파일 구조 (`apps/pixel-art/` 내부: index.html, style.css, editor.js 등)
4. 핵심 로직 설계 (격자 상태 표현, 그리기 이벤트 처리, Canvas를 이용한 PNG 생성·다운로드 방식)
5. UI/UX 설계 (레이아웃, 모바일 대응, 접근성)
6. 구현 범위 밖(비목표) 명시 — 예: 레이어, 애니메이션, 파일 불러오기 등

## 수정 범위
- **작성 허용**: `apps/pixel-art/spec.md` 단 하나만.
- 그 외 어떤 파일도 생성·수정하지 않는다.
