# Review 서브에이전트 지침 — 픽셀 아트 에디터

## 역할
Build 서브에이전트가 구현한 픽셀 아트 에디터를 검증하고 `apps/pixel-art/review.md`를 작성한다.
당신은 Build 서브에이전트와 별개의 검증자다. 구현을 옹호하지 말고 비판적으로 확인한다.

## 검증 대상
- `apps/pixel-art/index.html`, `style.css`, `editor.js`
- 기준 문서: `apps/pixel-art/spec.md`

## 검증 방법

### 1. 코드 리뷰 (정적)
- spec.md의 기능이 모두 구현되었는지: 16×16 격자, 드래그 연속 찍기, 기본 16색 팔레트 + 커스텀 피커, 지우개, 전체 지우기(confirm), PNG 다운로드(320×320, 투명 유지).
- 접근성: lang="ko", 버튼 텍스트 라벨, aria-pressed 상태, 터치 대상 44px.
- file:// 호환(`defer` 일반 스크립트, ES 모듈 미사용, fetch 미사용).

### 2. 로직 테스트 (Node)
- editor.js의 순수 로직(좌표 변환, 상태 배열 갱신, PNG 좌표 계산)을 Node에서 검증한다.
- 임시 테스트 파일은 스크래치패드 등 저장소 밖에 두거나 검증 후 삭제한다.

### 3. 브라우저 실행 검증
- 다른 세션의 정적 서버가 http://localhost:8642 에서 dist/를 서빙 중일 수 있으나, dist에는 아직 이 앱이 없다.
  임시 로컬 서버를 띄워 `apps/pixel-art/index.html`을 열어 검증하고, 끝나면 서버를 반드시 종료한다. (이전 검증에서 file:// 탐색은 브라우저 패널이 차단했음)
- 확인 항목:
  - 초기 화면: 16×16 격자(체커보드), 팔레트, 도구 버튼, PNG 저장 버튼 표시
  - 셀 클릭으로 도트 찍기, 드래그로 연속 찍기 (pointer 이벤트 합성 가능)
  - 색 변경 후 찍기, 지우개로 지우기, 전체 지우기
  - PNG 저장: 다운로드 링크의 dataURL을 디코드해 320×320 크기와 픽셀 색·투명도 확인 (canvas.toDataURL 결과 검사로 대체 가능)
  - 콘솔 에러 없음
  - 375px 폭에서 가로 스크롤 없음, 터치 대상 44px 이상
  - 다크 모드 렌더링 정상
- 참고: 이 환경에서 브라우저 패널 screenshot 액션이 타임아웃될 수 있다. 그 경우 DOM/computed style 검사로 대체하고 review.md에 명기한다.

## 문제 발견 시
- `apps/pixel-art/` 내 index.html, style.css, editor.js를 직접 수정해 고친다. 수정 내용은 review.md에 기록한다.
- 스펙 자체의 문제라면 수정하지 말고 review.md에 이슈로만 기록한다.

## 수정 범위
- **작성 허용**: `apps/pixel-art/review.md`, 그리고 문제 수정 시 `apps/pixel-art/index.html`, `style.css`, `editor.js`.
- 그 외 파일은 절대 수정하지 않는다. 특히 git 작업 영역에 있는 다른 변경(CLAUDE.md, css/, js/ 등)은 다른 작업의 것이므로 건드리지 않는다.

## review.md 형식
1. 검증 요약 (통과/수정 후 통과/실패)
2. 체크리스트 결과 표 (항목별 ✅/❌)
3. 발견한 문제와 수정 내역
4. 남은 이슈/개선 제안 (있다면)

## 완료 후
검증 결과(통과 여부, 발견·수정한 문제 수, 남은 이슈)를 요약해 반환한다.
