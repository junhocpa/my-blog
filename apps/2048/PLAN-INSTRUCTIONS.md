# Plan 서브에이전트 지침 — 2048 게임

## 역할
2048 퍼즐 게임 웹앱의 구현 계획(spec.md)을 작성한다. **코드는 작성하지 않는다.**

## 요구사항 (사용자 요청)
- 2048 게임: 방향키로 숫자 타일을 밀어서 같은 숫자를 합치는 퍼즐
- 점수판 포함

## 프로젝트 제약 (CLAUDE.md)
- 순수 HTML, CSS, JavaScript만 사용. 프레임워크/번들러 금지.
- 앱은 `apps/2048/` 폴더 안에 자체 완결되어야 한다.
- 외부 라이브러리 최소화 (CDN은 허용하나 2048은 바닐라 JS로 충분함).
- 모바일에서도 사용 가능해야 한다 (터치 스와이프 지원 포함).
- 블로그의 다른 파일은 건드리지 않는다.

## spec.md에 포함할 내용
1. 게임 개요 및 규칙 정의 (타일 이동/병합 규칙, 승리·패배 조건)
2. 기능 목록
   - 4x4 보드, 방향키 + 터치 스와이프 조작
   - 점수판: 현재 점수 + 최고 점수(localStorage 저장)
   - 새 게임 버튼, 게임 오버/승리 오버레이
3. 파일 구조 (`apps/2048/` 내부: index.html, style.css, game.js 등)
4. 핵심 로직 설계 (보드 상태 표현, 이동/병합 알고리즘, 랜덤 타일 생성)
5. UI/UX 설계 (레이아웃, 색상 방향, 모바일 대응 방식)
6. 구현 범위 밖(비목표) 명시 — 예: 애니메이션 고도화, 온라인 랭킹 등

## 수정 범위
- **작성 허용**: `apps/2048/spec.md` 단 하나만.
- 그 외 어떤 파일도 생성·수정하지 않는다.

## 완료 후
spec.md의 핵심 내용을 5줄 이내로 요약해서 반환한다.
