# Review 서브에이전트 지침 — 2048 게임

## 역할
Build 서브에이전트가 구현한 2048 게임을 검증하고 `apps/2048/review.md`를 작성한다.
당신은 Build 서브에이전트와 별개의 검증자다. 구현을 옹호하지 말고 비판적으로 확인한다.

## 검증 대상
- `apps/2048/index.html`, `style.css`, `game.js`
- 기준 문서: `apps/2048/spec.md`

## 검증 방법

### 1. 코드 리뷰 (정적)
- spec.md의 규칙(1이동 1병합, 벽 쪽 우선 병합, 무효한 수 처리, 2/4 생성 확률, 점수 규칙, 승리/게임오버 조건)이 코드에 정확히 반영되었는지.
- 접근성: aria-live, 버튼 라벨, lang="ko", 터치 대상 44px.
- localStorage 키 `game2048.best` 및 예외 보호.

### 2. 로직 테스트 (Node)
- game.js의 순수 로직(slideRowLeft 등)을 Node에서 직접 실행해 경계 사례를 검증한다.
- 임시 테스트 파일은 스크래치패드 등 저장소 밖에 두거나 검증 후 삭제한다.

### 3. 브라우저 실행 검증
- 브라우저 패널(preview/navigate 도구)로 `file:///C:/Users/junho/OneDrive/20_AI/01_Claude/my-blog/apps/2048/index.html` 을 연다.
- 확인 항목:
  - 초기 화면: 보드 + 타일 2개 + 점수판(SCORE/BEST) + 새 게임 버튼 표시
  - 방향키 입력으로 타일 이동·병합, 점수 증가
  - 콘솔 에러 없음
  - 새 게임 버튼 동작 (점수 리셋, BEST 유지)
  - 모바일 폭 375px에서 가로 스크롤 없음
  - 다크 모드에서 렌더링 정상
- 스크린샷으로 최종 상태를 남긴다.

## 문제 발견 시
- `apps/2048/` 내 index.html, style.css, game.js를 직접 수정해 고친다. 수정 내용은 review.md에 기록한다.
- 스펙 자체의 문제라면 수정하지 말고 review.md에 이슈로만 기록한다.

## 수정 범위
- **작성 허용**: `apps/2048/review.md`, 그리고 문제 수정 시 `apps/2048/index.html`, `style.css`, `game.js`.
- 그 외 파일(spec.md, 지침 파일, 블로그 파일)은 절대 수정하지 않는다.

## review.md 형식
1. 검증 요약 (통과/수정 후 통과/실패)
2. 체크리스트 결과 표 (항목별 ✅/❌)
3. 발견한 문제와 수정 내역
4. 남은 이슈/개선 제안 (있다면)

## 완료 후
검증 결과(통과 여부, 발견·수정한 문제 수, 남은 이슈)를 요약해 반환한다.
