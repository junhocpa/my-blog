이 블로그의 빌드 스크립트가 지원하는 마크다운 문법을 한눈에 정리합니다. 이 글 자체가 렌더링 테스트를 겸합니다.

## 텍스트 서식

문단 안에서 **굵게**, *기울임*, ~~취소선~~, `인라인 코드`를 쓸 수 있습니다. [링크](https://example.com)도 물론 지원합니다.

## 목록

순서 없는 목록:

- 첫 번째 항목
- 두 번째 항목
  - 중첩된 항목 하나
  - 중첩된 항목 둘
- 세 번째 항목

순서 있는 목록:

1. 마크다운으로 글을 쓴다
2. `node build.js`를 실행한다
3. `dist/` 폴더를 배포한다

## 인용문

> 좋은 글은 짧은 글이 아니라, 더 뺄 것이 없는 글이다.
> 인용문은 여러 줄로 이어서 쓸 수 있습니다.

## 표

| 기능 | 지원 여부 | 비고 |
| --- | :---: | ---: |
| 제목 | ✅ | h1~h6 |
| 코드 블록 | ✅ | 구문 하이라이팅 포함 |
| 표 | ✅ | 정렬 지원 |
| 각주 | ❌ | 미지원 |

## 코드 블록

```js
// 코드 블록은 언어를 지정하면 하이라이팅됩니다
function greet(name) {
  return `안녕하세요, ${name}님!`;
}
console.log(greet('독자'));
```
